# КОНТЕКСТ ПРОЕКТА
Разрабатываем мобильное приложение-блог для родового целителя, арт-терапевта и духовного наставника Дины Кануниковой (сайт https://pulsera.ru/).

Приложение должно:
- Предоставлять бесплатный и платный контент (статьи, видео-медитации, аудио-практики, курсы, персональные разборы)
- Работать на iOS и Android (в будущем возможна веб-версия)
- Иметь систему подписки на премиум-контент
- Поддерживать офлайн-режим

# ТЕХНОЛОГИЧЕСКИЙ СТЕК
- React Native + Expo (последняя версия)
- Expo Router (файловая система роутинга)
- TypeScript (строгая типизация)
- Zustand для state management
- Supabase для backend (auth, database, storage, realtime)
- RevenueCat для управления подписками
- React Native Video для видео
- expo-av для аудио
- expo-notifications для push
- expo-file-system + expo-sqlite для офлайн-режима
- React Native Reanimated для анимаций

# СТРУКТУРА ПРИЛОЖЕНИЯ

## Табы (Bottom Navigation):
1. **Главная** — лента нового контента, рекомендуемое, баннеры
2. **Каталог** — весь контент по категориям (статьи, медитации, курсы)
3. **Чат/Сообщество** — комментарии, обсуждения, профиль
4. **Профиль** — настройки, подписка, закладки, скачанное

## Экраны:
- Онбординг (3-4 экрана)
- Регистрация / Вход (email, пароль, OAuth, magic link)
- Главная с лентой контента
- Категория контента (список статей/медитаций)
- Детальный экран контента:
  - Для статьи: Markdown-рендеринг с изображениями
  - Для видео: плеер с фоновым воспроизведением
  - Для аудио: плеер с фоновым воспроизведением
  - Для курса: прогресс, уроки
- Платный контент: блюр + кнопка "Разблокировать"
- Плеер (мини-плеер внизу + полноэкранный)
- Поиск по контенту
- Закладки / Избранное
- Скачанное (офлайн)
- Профиль пользователя
- Управление подпиской
- Настройки (тема, язык, уведомления, выход)
- Чат с автором (через Supabase Realtime)
- Комментарии к контенту

# СИСТЕМА ПОДПИСКИ
## Тарифы:
1. **"Путь"** (Базовый) — ежемесячная/годовая
   - Все статьи
   - Все видео-медитации
   - Все аудио-практики

2. **"Пробуждение"** (Премиум) — ежемесячная/годовая
   - Всё из тарифа "Путь"
   - Все курсы
   - Персональные разборы (лимитированно в месяц)

## Логика:
- Бесплатный контент виден всем
- Платный контент показывает превью + блюр
- При попытке открыть платный контент → модалка с предложением подписки
- Проверка подписки через RevenueCat
- Восстановление покупок

# OFFLINE РЕЖИМ

# БАЗА ДАННЫХ (Supabase)

## Таблицы:
- profiles (user_id, display_name, avatar_url, created_at)
- content (id, title, description, type, category, content_data, is_premium, subscription_tier, created_at)
- user_content_progress (user_id, content_id, progress, last_position, is_downloaded)
- bookmarks (user_id, content_id, created_at)
- comments (id, user_id, content_id, text, created_at, parent_id)
- chat_messages (id, user_id, message, created_at, read)
- subscriptions (user_id, tier, status, expires_at)

## Row Level Security (RLS):
- Пользователи видят только свои данные
- Публичный контент доступен всем
- Платный контент проверяется через функцию проверки подписки
